# 3ds Max 2025
Termos: mover (Move, W), girar (Rotate, E), escala (Scale, R), espelhar (Mirror, menu Tools > Mirror), alinhar (Align), clonar/copiar (Shift+arrastar), renderizar (Render), material (Material Editor, M), luz (Light), câmera (Camera), modificador (Modifier).
Atalhos padrão. Podem ser alterados em Customize > Hotkey Editor.

## Seleção e transformação
Q: selecionar. W: mover (Select and Move). E: girar (Select and Rotate). R: escala (Select and Scale).
H: Select by Name (lista de objetos). Ctrl+A selecionar tudo. Ctrl+I inverter seleção. Ctrl+D desmarcar.
Espaço: trava a seleção atual. Shift + arrastar com mover/girar/escala: clona (Copy, Instance, Reference).
Alt+A: Align (alinhar a outro objeto). Tecla X: liga/desliga o gizmo de transformação.
F12: digitar valores exatos de transformação.

## Vistas
T topo, B inferior, F frente, L esquerda, P perspectiva, U ortográfica do usuário, C câmera.
Z: zoom extents no objeto selecionado (ou em tudo, se nada selecionado). Alt+W: maximiza/restaura a viewport.
F3: alterna wireframe/sombreado. F4: mostra arestas sobre o sombreado (Edged Faces). Alt+X: objeto transparente (See-Through).
Alt+Q: isola a seleção. Ctrl+C: cria câmera a partir da vista atual. Shift+Z: desfaz mudança de vista.
G: liga/desliga a grade. 7: estatísticas de polígonos na viewport.

## Snaps
S: liga/desliga snap. A: snap de ângulo. Botão direito no ícone de snap abre as opções (vértice, aresta, ponto médio, grade).

## Modelagem
Modificadores (aba Modify): Edit Poly, TurboSmooth, Shell (espessura), Symmetry, Bend, Taper, Twist, FFD, Chamfer, Extrude, Lathe (revolução), Sweep, UVW Map, Unwrap UVW, Noise.
No Edit Poly: 1 vértice, 2 aresta, 3 borda, 4 polígono, 5 elemento. Ctrl+Backspace remove aresta/vértice sem deixar buraco.
Ferramentas comuns do Edit Poly: Extrude, Bevel, Inset, Chamfer, Connect, Cut, Bridge, Cap, Weld, Target Weld, Swift Loop, Loop e Ring.
Splines: Line, Rectangle, Circle, Text; com Extrude viram sólidos, com Lathe giram, com Sweep percorrem um perfil.
Importar DWG/DXF do AutoCAD: File > Import (unidades em mm: Customize > Units Setup).

## Materiais e renderização
M: Material Editor (Slate). O motor padrão é o Arnold (materiais Physical Material ou Standard Surface).
F10: Render Setup. Shift+Q ou F9: renderizar (F9 repete o último render). 8: Environment and Effects.
Iluminação: luzes Arnold Light ou Physical Sun & Sky para externas. Câmera física: Physical Camera.

## Arquivos
Ctrl+N novo. Ctrl+O abrir. Ctrl+S salvar. Ctrl+Z desfazer (Edit > Undo). Ctrl+Y refazer.
File > Archive junta o arquivo com as texturas num ZIP. File > Merge traz objetos de outro arquivo .max.
Salvar para versão antiga: File > Save As > Save as type (até 3 versões anteriores).
